## Open source

Two pieces of the system are public. You run them on hardware you control.

| Product | What it is |
|---------|------------|
| **[Watchtower](https://github.com/braintied/watchtower)** | Records what coding agents tried, which attempts failed, and the error that came back. Capture client. Apache-2.0. |
| **[Research](https://github.com/braintied/research)** | You name the question and a dollar cap. It searches, fetches, cites, and grounds every claim against the fetched page. |

Watchtower does not call a model. Research does not spend until you set a cap.

Also public, smaller: [agentlog](https://github.com/braintied/agentlog) (session JSON) and [kimi-router](https://github.com/braintied/kimi-router) (Kimi key pool).
